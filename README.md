# ServiceRunner

Нативное macOS-приложение (SwiftUI) для запуска локальных сервисов: старт/стоп одной кнопкой, статус в окне и в menu bar, логи с фильтром.

## Сборка и запуск

```bash
./scripts/build-app.sh
open build/ServiceRunner.app        # или перетащить в /Applications
```

Требования: macOS 14+, Xcode / Swift 5.9+. Тесты: `swift test`.

Иконка рисуется кодом в `scripts/make-icon.swift` и лежит в `Resources/AppIcon.icns`; после правок скрипта: `swift scripts/make-icon.swift Resources/AppIcon.icns`.

## Как это работает

- Команда выполняется через `$SHELL -l -c "<команда>"` — окружение как в терминале (PATH, nvm, brew).
- Каждый сервис — отдельная группа процессов. «Стоп» шлёт SIGTERM всей группе, через 5 с — SIGKILL, так что дочерние процессы (`npm run` → `node`) тоже завершаются.
- Автоперезапуск при падении с задержкой 1→2→4…→30 с; счётчик сбрасывается после 60 с стабильной работы.
- При падении — системное уведомление; клик открывает сервис.
- При выходе из приложения все сервисы останавливаются. Закрытие окна приложение не завершает — оно остаётся в menu bar.

## Файлы

- Конфиг: `~/Library/Application Support/ServiceRunner/services.json`
- Логи: `~/Library/Logs/ServiceRunner/<имя>-<id>.log` (в окне — последние 10 000 строк)

Горячие клавиши в окне сервиса: ⌘R — старт, ⌘. — стоп, ⇧⌘R — перезапуск.
